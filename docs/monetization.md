# Monetization Notes

## Recommended Model

Use free-to-start content with paid entity packs.

## Free Content

- The Watcher entity.
- First 3-5 rituals.
- Basic caught-card sharing.
- Daily challenge preview.

## Paid Content

- Entity packs: `$1.99-$2.99`.
- Bundle or season pass: `$6.99-$9.99`.
- Cosmetic caught-card frames.
- Special failure effects.

## Avoid Early

- Heavy interstitial ads.
- Paywalls before the first scare.
- Uploading user camera frames for server-side effects.

The game asks for camera trust. Monetization should feel clean.
